# cl-tools

A collection of Core Lightning tools and scripts for node management, data synchronization, and graph analysis.

## Directories

- **[`5satoshi/`](5satoshi/README.md)**: Core Lightning tools, scripts, and plugins for gathering analytics data for 5satoshi.com, syncing to BigQuery, and calculating network centrality.
- **[`fee-updates/`](fee-updates/README.md)**: Scripts and utilities for managing channel fees, analyzing competitive routes, and synchronizing network data.
- **[`graph-explorer/`](graph-explorer/README.md)**: Tools to interact with and explore the Lightning Network graph topology.
